# 中国地理・都市クイズ

GitHub Pagesで公開するためのファイル一式です。元のクイズはHTML単体で完結しており、地図データも埋め込み済みです。

## GitHub Pagesで公開
1. GitHubで新しいPublicリポジトリを作成
2. このフォルダの `index.html` / `manifest.webmanifest` / `sw.js` をアップロード
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)` を選択
4. 表示されたURLをiPhoneのSafariで開く
5. Safariの共有 → 「ホーム画面に追加」でアプリのように起動できます

誤答データはブラウザのlocalStorageに保存されます。端末間では共有されません。
